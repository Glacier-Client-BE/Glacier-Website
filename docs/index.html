Installation

  1. Download the Glacier .mcpack from the Downloads page.
  2. If the file doesn't end in .mcpack, rename it (ZArchiver on Android can do this).
  3. Open it to import into Minecraft, then activate it under Global Resources.

Full step-by-step instructions for Mobile, PC, and Console are in the FAQ.

Configuration

Edit config.json directly, or use the online Config Editor. Toggles use true/false, opacity uses 0.0–1.0, and offsets adjust HUD element position.

Android / iOS path:

Android/data/com.mojang.minecraftpe/files/games/com.mojang/resource_packs/Glacier/config.json

Windows path:

%userprofile%\AppData\Local\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\resource_packs\Glacier\config.json

What makes a Bedrock client "the best"?

The best Minecraft Bedrock client is safe to use on Realms and vanilla servers, doesn't inject code or grant gameplay advantages, and stays lightweight enough to run on mobile devices. Look for a resource-pack-based approach, active updates that keep pace with Minecraft's own releases, and a HUD you can actually customize.

Where Glacier Client fits

Glacier Client is a free resource pack for Minecraft Bedrock Edition with 37+ modules, a draggable HUD, and a config editor, built entirely on Minecraft's supported resource pack system rather than code injection. It runs on Mobile, PC, and Console (via Realms), at around 2MB with no measurable performance cost.
